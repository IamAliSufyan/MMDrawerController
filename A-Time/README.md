# A-Time

**A-Time** is a macOS **menu bar presentation timer**. It lives in the menu bar
and shows a **full-width, click-through overlay progress bar** pinned just below
the macOS menu bar. The bar is split into the sections of your talk and fills
section-by-section as you present — staying above every app while never stealing
focus or interrupting your flow.

Built with **Electron** (vanilla JS renderer, no bundler) so it packages cleanly
into a signed-or-unsigned **DMG**.

---

## Features

- 🎨 **Colorful menu bar icon** — shows the remaining time beside it while running.
- 🪟 **Clean main window** — large *New Timer* button + a list of saved timers
  (name, total time, section count, and Play / Edit / Duplicate / Delete).
- 📝 **Single-page timer editor** — name, total duration (up to 1 hour) and
  draggable sections. Each section: optional name, optional color, a 0–15 min
  slider, and an editable mm:ss field.
- 🧮 **Smart time reconciliation**
  - Section durations sum to the total automatically.
  - A total with empty sections is **split equally**.
  - A mismatch shows a popup with the entered total, the section total, the
    difference, and three choices (use sections / keep total & auto-adjust / go
    back).
- 🌈 **Default palette** — 9 pleasant colors assigned in order (wrapping when
  there are more sections than colors).
- 💾 **Local persistence** — timers and settings survive restarts (via
  `electron-store`).
- ⏳ **3-2-1 countdown** before each run (full-screen, centered, silent).
- 📊 **Overlay** — one horizontal bar split into sections; light-gray until each
  section fills with its color. Shows the current section title, section
  remaining, total remaining, and the current clock time. Auto light/dark.
- 🖱️ **Click-through** — the whole overlay passes clicks through to the apps
  underneath; only the small **Pause / Resume / Stop / Reset** controls on the
  right are interactive.
- ⌨️ **Global shortcuts** — `Space` pause/resume, `⌘R` restart, `⌘→` next
  section, `⌘←` previous section, `Esc` stop.
- 🔋 **Sleep prevention** while running (released on pause/stop/complete).
- 🔊 **Built-in sounds** — a soft chime at each section end, a distinct chord at
  the very end (synthesized, no external files).
- 🔔 **Completion** — final sound + macOS notification, then the overlay hides.
- 🖥️ **Multi-monitor** — overlay on the main screen, all screens, or a chosen
  display.

## Requirements

- **macOS** — latest version plus the previous two major releases
  (the packaged app targets `minimumSystemVersion: 12.0`).
- **Node.js 18+** and **npm** (for development / building).
- **Xcode Command Line Tools** (`xcode-select --install`) — provides `iconutil`,
  needed to build the `.icns` and the DMG.

> The app itself is macOS-only at runtime (menu bar, overlay window levels,
> global shortcuts, sleep prevention). The pure timer logic is unit-tested and
> runs on any platform.

## Project structure

```
A-Time/
├── package.json
├── electron-builder.yml         # DMG / universal target + entitlements
├── build/
│   ├── entitlements.mac.plist
│   └── (icons generated by `npm run icons`)
├── scripts/
│   ├── iconGen.js               # pure-Node PNG icon renderer (+ runtime fallback)
│   ├── generate-icons.js        # writes app/tray icons + .icns
│   └── make-dmg.sh              # one-command DMG build
├── src/
│   ├── core/                    # PURE timer logic (no Electron) — unit tested
│   │   ├── timerEngine.js       # drift-free countdown + section transitions
│   │   ├── timeCalc.js          # totals, equal split, proportional adjust
│   │   ├── palette.js           # default colors
│   │   └── validation.js
│   ├── main/                    # MAIN process
│   │   ├── main.js  tray.js  windows.js  overlayManager.js
│   │   ├── controller.js        # orchestrates engine + overlay + sounds + power
│   │   ├── ipc.js  store.js  powerManager.js  shortcuts.js  sounds.js
│   ├── preload/preload.js       # safe contextBridge API
│   └── renderer/
│       ├── main/                # list, form, sectionRow, mismatchModal, settings
│       ├── overlay/             # progress bar + controls
│       └── countdown/           # 3-2-1
└── test/                        # node --test unit tests
```

Timer logic is intentionally kept **separate from the UI**: `src/core/` has no
Electron or DOM dependencies and is exercised directly by the tests.

## Setup

```bash
cd A-Time
npm install
```

## Run (development)

```bash
npm start
```

The app launches into the **menu bar** (no Dock icon). Click the colorful
menu bar icon to open a compact **popover** with a *New Timer* button and your
saved timers (play / edit / duplicate / delete). Editing or creating a timer
opens the full window. A sample timer — **“Sadiqabad City Presentation”** — is
seeded on first launch.

## Test (works on any OS)

```bash
npm test
```

Runs the pure-logic unit tests (`time calc` reconciliation incl. the 15-vs-18
example, equal split, proportional adjust; engine transitions, pause/resume,
next/previous, completion).

## Build icons

```bash
npm run icons
```

Generates `build/icon.png`, the tray icons, and (on macOS) `build/icon.icns`.

## Build the DMG

```bash
npm run dmg
# or:  npm run build      (icons + electron-builder universal)
```

The DMG is written to `dist/`. `make-dmg.sh` installs dependencies if needed,
generates icons, then runs `electron-builder --mac dmg --universal`.

### Code signing (optional)

By default the DMG is **unsigned**. To distribute without a “damaged app”
warning, sign + notarize with your Apple Developer credentials:

```bash
export CSC_LINK=/path/to/certificate.p12
export CSC_KEY_PASSWORD=your-cert-password
export APPLE_ID=you@example.com
export APPLE_APP_SPECIFIC_PASSWORD=xxxx-xxxx-xxxx-xxxx
export APPLE_TEAM_ID=YOURTEAMID
npm run build
```

To run an **unsigned** local build, right-click the app → *Open*, or:

```bash
xattr -cr "/Applications/A-Time.app"
```

## Keyboard shortcuts (active while a timer runs)

| Shortcut | Action            |
|----------|-------------------|
| `Space`  | Pause / Resume    |
| `⌘ R`    | Restart timer     |
| `⌘ →`    | Next section      |
| `⌘ ←`    | Previous section  |
| `Esc`    | Stop timer        |

## Final testing checklist

Run on a Mac after `npm start` (or after installing the DMG):

- [ ] App appears in the **menu bar** (colorful icon, no Dock icon).
- [ ] Clicking the menu bar icon opens the compact popover (and does **not**
      affect a running timer); New/Edit open the full window.
- [ ] **New Timer** opens the single-page form.
- [ ] Sections can be added, removed, recolored, and **dragged to reorder**.
- [ ] Slider and mm:ss field stay in sync (0–15 min per section).
- [ ] Creating the sample (total 15 min, sections 3+5+6+4 = 18 min) shows the
      **mismatch popup** with `+3:00` difference and all three options.
- [ ] Timers **save** and persist after quitting and relaunching.
- [ ] **Edit**, **Duplicate**, and **Delete** all work.
- [ ] **Play** shows the full-screen **3-2-1** countdown (silent), then the
      overlay.
- [ ] Overlay sits just **below the menu bar**, full width, above all apps.
- [ ] Overlay is **click-through** (you can click apps behind it) except the
      controls on the right.
- [ ] Sections **fill** with their colors and auto-advance.
- [ ] Remaining time shows **beside the menu bar icon** while running.
- [ ] **Soft sound** at each section end; **distinct sound** at the final end.
- [ ] macOS **notification** appears at completion; overlay then **hides**.
- [ ] **Pause / Resume / Stop / Reset** controls work.
- [ ] **Keyboard shortcuts** (Space, ⌘R, ⌘→, ⌘←, Esc) work.
- [ ] **Settings**: overlay height, opacity, and monitor behavior persist and
      apply live.
- [ ] The Mac **does not sleep** while a timer runs; sleep is allowed again once
      paused/stopped/completed.
- [ ] `npm run dmg` produces a mountable DMG in `dist/`.
